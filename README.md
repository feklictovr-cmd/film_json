# Каталог фильмов на Django (только JSON)

## Запуск в Windows PowerShell

Перейдите в папку проекта, где находятся `manage.py` и `requirements.txt`, затем выполните:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ . Если виртуальное окружение уже создано, повторно создавать его не нужно.

## Возможности
- HTML-форма добавления фильма: название, режиссёр, год выпуска и жанр.
- Каждый фильм сохраняется в отдельный JSON-файл.
- Загрузка только JSON-файлов с проверкой структуры и полей до сохранения.
- Максимальный размер загружаемого файла — 2 МБ.
- Имя файла генерируется сервером, исходное имя пользователя не используется как путь.
- Просмотр сохранённых фильмов и сообщение, если файлов ещё нет.
- Ссылка для скачивания примера JSON.

В проекте не используется XML. Настройки `DEBUG=True` и тестовый `SECRET_KEY` подходят только для локальной учебной работы, не для публикации в интернете.
